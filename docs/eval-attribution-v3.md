# v3 指标下降归因（2026-10-11）

> 结论先行：**同口径 fact 级 Rec@5 从 87.0% → 79.6% 的 −7.4pt，全部集中在 3 条查询、2 道题上**：
> 其中 **−4.6pt 是解析层在贝莱德 p14–p16 的阅读顺序回归**（真缺陷），
> **−2.8pt 是精排排序差异**（非解析问题）。
> 另外，早先「v2 虚高（chunk overlap）」的归因**不成立**——见 §5 更正。

---

## 1. 先把三个「降低」拆开

同一批查询、同一台索引，数字却有几个不同说法。它们不是一回事：

| 对比 | 数字 | 性质 |
|---|---|---|
| v2 fact 级 87.0% → v3 fact 级 79.6%（13 题 39 查询 108 fact 实例） | −7.4pt | **真降**，但只有 3 条查询贡献 |
| v3 fact 级 83.7% → chunk 级 gold 63.2% | −20.5pt | **纯换尺子**，检索没变（全题口径） |
| 63.2% 这个数本身 | — | **尺子标错**：gold 含 46.2% 冗余块，分母虚大（已修，见 §6） |

本报告解决第一行。

`v2 基线 2026-10-10_23.35.42` 与 `v3 同题子集 2026-10-11_19.44.28` 逐条对齐
（39 条查询 × 每题 2–4 个 fact）：

| 查询 | fact 命中 v2 → v3 | Δ | 丢的 fact |
|---|---:|---:|---|
| **blk-q4 / en** | 4 → 2 | −2 | 长期投资级别信用债低配、中国持中性观点 |
| **blk-q4 / zh** | 4 → 2 | −2 | 同上 |
| **blk-q4 / mixed** | 3 → 2 | −1 | 中国持中性观点 |
| **icct-q6 / en** | 3 → 2 | −1 | 新兴市场合计200万 |

## 3. 根因 A：解析层在贝莱德 p14–p16 的阅读顺序回归（−4.6pt）

### 3.1 现象：同一页，两种读法

贝莱德 p16「战术配置细分观点」是**左右并列的两张表**（左 `股票`、右 `固定收益资产`，
各含 资产 / 观点图 / 评论 三列）。两句事实在两版索引里的原文对比：

```
v2（正确，行序）  长期投资级别信用债我们持低配观点。相比长期债券，我们偏好较不易受利率风险影响的短期债券。
v3（错乱，交错）  长期投资级别我们持低配观点。相比长期债券，我们偏好较不易受利率风险影信用债响的短期债券。
                 ^^^^^^^^^^^^^^ 资产名被劈开            ^^^^^^ 评论文中间插入「信用债」
```

v3 不但把两张表串在一起，还把**资产名插进了评论句中**、把词从中间劈开
（`风险影 | 信用债 | 响的短期债券`）。因此所有**跨单元格相邻**的锚点
（`中国我们持中性观点`、`长期投资级别信用债我们持低配观点`）在 v3 里 0 命中。

### 3.2 机理（三步，逐层可复现）

1. **`group_lines` 只按 y 合并、不按 x 间隙切分**（`pdf_layout.py:200`）。
   左右两张表在同一水平带上的 span 被并成**同一个 Line**——实测 p16 出现
   `x[221,767]` 这种跨 546pt 的「行」：

   ```
   y 132.8  x[221,767]  我们持超配观点。美国企业盈利强劲，部分由我们持低配观点。我们认为高企的债务偿付成本…
   ```
   （前半是**左表**的评论，后半是**右表**的评论。）

2. **`analyze_columns` 因此判 `no_gap`**——行已被跨栏合并，分栏缝自然不存在：

   ```
   verdict : single
   notes   : ['no_gap']
   regions : [(24.3, 587.0, 'no_gap', 1)]
   ```

3. **`reading_order_lines` 退回全局 y 排序**，于是两表的行按 y 交替输出，读串。

补充一条**放大伤害**的版面事实：资产名在行内**垂直居中**，其评论常 2–3 行，
所以按 y 排序时资产名会落在自己评论句的中间（`中国` y=458.9，其评论从 y=435.2 开始）。
这也是为什么**即使把两张表正确切开，纯重排也还原不出「资产名 + 评论」的相邻关系**——
那需要真正的表格结构还原。

### 3.3 试过并否决的三种修法

| 修法 | 结果 | 否决理由 |
|---|---|---|
| 打开 `find_tables(strategy="text")` | p14/p15/p16 确实各抓到 1 张完整表（p16 = 71 行×6 列，行序正确） | **在 ICCT 35/36 页、贝莱德 5 页散文页上造出假表**（把整页正文凑成一张 87×8 的「表」）。现存护栏（面积 ≥25% 页 + 页外文本行 ≤4）失效——假表盖满整页后「页外行」自然就少 |
| `group_lines` 按 x 间隙切分 | p16 的间隙分布**干净的雙峰**（<2pt 有 29 个、≥10pt 有 59 个、2–10pt **一个都没有**），切分本身可行 | 切完仍**不恢复行关联**（资产名垂直居中，见 3.2 末）。且 ICCT 双栏页、贝莱德版式页同样大量存在宽间隙，切分无法区分「栏缝」与「表内单元格缝」 |
| 用「纵向空白带」判别真假表 | — | **完全无区分度**：假表页的空白带 76–88pt，真表页 32–86pt，重叠 |

结论：**廉价启发式无法安全区分**，这是个需要表格结构还原（或引入 `pymupdf_layout` /
Docling 等版面模型）的功能，已单列为已知问题（见 §7）。

## 4. 根因 B：icct-q6 / blk-q1 的排序差异（−2.8pt）

这两处**不是解析问题**——锚点在 v3 索引里完好存在：

| 锚点 | v3 命中 | v2 命中 |
|---|---|---|
| `approximately 2 million EVs were sold in these markets collectively` | p2/body，337 字符 | p2/body，**337 字符（与 v3 逐字相同）** |
| `5-8万亿` / `5至8万亿` | p4/body | p4/body |

文本仍在、且 icct-q6 的承载块与 v2 **完全相同**，说明这是**精排后的排序差异**
（同一批候选，v3 的 top-5 里没排进来）。样本只有 39 条查询，单条 fact 的波动即 ±0.9pt，
这 −2.8pt 属噪声量级，不构成系统性退化。

## 5. 更正：早先「v2 虚高」的归因不成立

`docs/pdf-parsing-step7.md` 曾把 v2→v3 的下降归因为
「v2 的 400 字滑窗 + 80 字重叠让同一事实在多块重复出现 ⇒ 命中被重复计数 ⇒ v2 虚高」。
证据是「贝莱德每锚点命中块数 2.05 → 1.26」。

**该结论对「下降」的解释是错的**，理由：

- 若 overlap 冗余是主因，下降应**弥散在多道题**上；实测 5 道 blk 题里只有 blk-q4 掉分，
  blk-q2/q3/q5/q6 **一点没变**（+0）。
- 下降的 63% 出自 p16 的阅读顺序回归（§3），与 overlap 无关。
- 「2.05 → 1.26」是**关于切块方式的事实描述**（v3 按节切、跨节不再重叠），
  它影响的是 **chunk 级指标的分母**，不是 fact 级命中——两者被混为一谈了。

保留正确的部分：v3 跨节不再重叠是真的；受它影响的是 gold 的冗余（§6），
而不是本节的 fact 级下降。

## 6. 已修的：chunk 级 gold 的冗余（尺子标错）

`build_gold.py` 原先收「所有含锚点的块」进 gold。切块有两处重叠——节内超长保留
80 字 `CHUNK_OVERLAP`、超大表格分块重复表头——同一句话会同时落进相邻两块，
两块都算 gold ⇒ 分母虚大。

实测：**39 个 gold 块里 12 个（30.8%）的命中集合被其他块完全覆盖**，属纯冗余。
`icct-q2` 的两个 gold 就是同一段被 overlap 切开的两半；`blk-q2` 4 块里 3 块冗余。

修法：gold 改为**最小覆盖集**（贪心集合覆盖 + 同分取靠前块），39 → **27**；
`--check` 新增 **WARN-REDUNDANT** 审计，以后换解析器/改切块时能自动抓出这类污染。

### 6.1 修完后：两个数字反向移动，但都是同一个修正

| 指标（hybrid_rerank） | 冗余 gold（39 块） | 最小覆盖（27 块） | 方向 | 解释 |
|---|---:|---:|---|---|
| ★chunk Rec@5 | 63.2% | **76.5%** | ↑ +13.3pt | 分母不再含重复块 |
| ★AP@5 | 0.747 | **0.689** | ↓ −0.058 | 一个答案只算一次（原来两个重叠块各算一个相关命中） |
| ★MRR@5 | 0.739 | **0.686** | ↓ −0.053 | 同上 |
| NDCG@5 | 0.803 | **0.760** | ↓ −0.043 | 同上 |

**方向相反不是矛盾**：两处都由「同一个答案在重叠块里被算了两次」引起。分母端（Recall）
被重复放大 ⇒ 修后**上升**；分子端（相关块计数）被重复计入 ⇒ 修后**下降**。
按最小覆盖集的口径，`0.689 / 0.686 / 0.760` 才是去重后的诚实值，
原先的 `0.747 / 0.739 / 0.803` **同样是虚高**。

重跑结果（`app/eval/results/2026-10-11_20.51.49__retrieval__*.{md,json}`，16 题 / 45 锚点 / 27 gold）：

| 模式 | ★Rec@5(chunk) | ★AP@5 | ★MRR@5 | NDCG@5 | 池召回(gold) | P50 |
|---|---:|---:|---:|---:|---:|---:|
| bm25 | 37.0% | 0.278 | 0.292 | 0.333 | 48.1% | 1ms |
| keyword(ES) | 35.8% | 0.272 | 0.286 | 0.323 | 43.2% | 64ms |
| vector | 38.3% | 0.321 | 0.323 | 0.383 | 76.5% | 171ms |
| hybrid(RRF) | 46.9% | 0.383 | 0.379 | 0.445 | 82.7% | 222ms |
| **hybrid_rerank** | **76.5%** | **0.689** | **0.686** | **0.760** | **88.9%** | 820ms |

精排增益：gold 口径 46.9 → 76.5（**+29.6pt**）、MRR 0.379 → 0.686；
fact 口径 52.6 → 83.7（+31.1pt）。加深池只再补 **+8.6pt**（池 88.9% → 97.5%），
说明**剩余缺口主要在排序而非召回**——与 fact 口径下的结论一致。

## 7. 已修的：blk-q4 锚点改为「读法无关」

原重校把锚点改成 `长期投资级别我们持低配观点`——该串**只在 v3 的错乱读法里存在**，
等于把解析缺陷固化成标准答案，解析器一旦修好 gold 立刻失效。

现改为 `我们持低配观点。相比长期债券`：在 **v2 与 v3 两种读法下都连续**、
且在库内唯一。原则是——

> 锚点是检索层的评测对象，不应隐含「跨单元格相邻」这种**解析层属性**。
> p16 的阅读顺序缺陷应由解析层的检查来测，而不是靠检索锚点去碰。

## 8. 结论

1. **v3 相对 v2 的真实退化 = 1 个解析缺陷（贝莱德 p14–p16 并列双表阅读顺序）**，
   影响 3 页 / 1 份文档；此外 −2.8pt 是排序噪声，不是退化。
2. **v3 的收益没有被抵消**：ICCT 乱码 chunk 20.3% → 0、页码双轨、按节切块、
   表格独立成块（21 个 table chunk，逐格 100% 对齐）——这些是 v2 完全没有的。
3. **主指标已换 chunk 级 gold**（见 `docs/eval-testset-v3.md`），但 gold 必须先修
   冗余（本报告 §6），否则跨版本仍不可比。
